# Open Metadata Exchange — Odisee Agile Team Project

We are a team of six Electronics-ICT students at [Odisee](https://www.odisee.be),
contributing to the [Open Metadata Exchange (OME)](https://github.com/ISKME/Open-Metadata-Exchange)
for [ISKME](https://www.iskme.org) during the Agile Team Project 2026–2027.

OME is an open-source network that lets educational platforms share open learning
resources with each other, so material stays findable and available even when a
single platform disappears.
